# Credits and provenance

Aura Soulflame started as Bum-Boo's personal desktop customization. The palette, Kitty settings, and QML effects here are the portable resources. The Plasma colors use the theme's named palette. The portable Plasma packages contain their QML and use the host desktop's existing icon theme and window decorations.

The repository's original code, documentation, and skill are available under the [MIT license](../LICENSE). The same license is included in the standalone skill ZIP.

The README title artwork is typeset in [UnifrakturMaguntia](https://fonts.google.com/specimen/UnifrakturMaguntia).

The personal build used assets derived from [Daemon KDE](https://github.com/MathisP75/daemon-kde-mk2) and [Breeze Icons](https://github.com/KDE/breeze-icons). Those files have their own licenses. Character artwork is supplied independently through the local asset format. The personal concept was inspired by [Aura from Frieren: Beyond Journey's End](https://frieren-anime.jp/character/chara_group2/2-2/).

Platform references are [KDE Plasma theme packaging](https://develop.kde.org/docs/plasma/theme/theme-porting-to-plasma6/), [KDE widget packaging](https://develop.kde.org/docs/plasma/widget/setup/), and [Kitty configuration](https://sw.kovidgoyal.net/kitty/conf.html).
