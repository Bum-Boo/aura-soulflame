# Credits and provenance

Aura Soulflame started as Bum-Boo's personal desktop customization. The palette, Kitty settings, and QML effects form the portable base. The collection also includes the optional Plasma workspace style and icon theme.

Aura Soulflame is an unofficial fan-made project inspired by Aura from the anime *Frieren: Beyond Journey’s End*. The character sheets, portraits, wallpapers, cursors, login and boot images that show Aura, the launcher icon, and the pet sprite were generated with OpenAI's GPT image generation. They are for personal, non-commercial fan use and are not covered by the MIT license. Rights in the character and the original work remain with their respective rights holders. The anime's official character page credits © 山田鐘人・アベツカサ／小学館／「葬送のフリーレン」製作委員会. [Official Aura character page](https://frieren-anime.jp/character/chara_group2/2-2/) · [Asset terms and excluded paths](../ASSETS-LICENSE)

The [MIT license](../LICENSE) covers the original code, scripts, configuration, documentation text, and original graphics that do not depict Aura, such as the abstract flame frames. The Aura Symbols font is outside that license because its head glyph depicts Aura. See the notices below for third-party components.

The README title artwork is typeset in [UnifrakturMaguntia](https://fonts.google.com/specimen/UnifrakturMaguntia).

- The [Plasma workspace style](../themes/plasma/styles/aura-soulflame) recolors the Daemon style for the Aura palette. See its bundled license and the original [Daemon KDE](https://github.com/MathisP75/daemon-kde-mk2).
- The [Plasma icon theme](../themes/plasma/icons/AuraSoulflame) recolors the Breeze folder and status SVGs. That Breeze art retains the bundled LGPL notice. The Aura launcher PNGs are character art and follow [ASSETS-LICENSE](../ASSETS-LICENSE). [Breeze Icons](https://github.com/KDE/breeze-icons)
- The **AuraSD-Character** and **AuraSD-Complete** cursor variants adapt Breeze cursor function glyphs. The [cursor directory](../assets/cursors) contains the Breeze notice, and the character sheets are under [art](../assets/character/art). [Breeze Cursors](https://github.com/KDE/breeze/tree/master/cursors)
- Plymouth Classic uses the host distribution's spinner prompt artwork. GRUB builds the text fonts from the host's installed Noto fonts and the bundled Aura Symbols.

Platform references are [KDE Plasma theme packaging](https://develop.kde.org/docs/plasma/theme/theme-porting-to-plasma6/), [KDE widget packaging](https://develop.kde.org/docs/plasma/widget/setup/), and [Kitty configuration](https://sw.kovidgoyal.net/kitty/conf.html).
